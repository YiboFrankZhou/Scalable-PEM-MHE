## Running the notebooks

Use Python 3.10. Install the dependencies and start Jupyter Notebook from the repository root:

```sh
python -m pip install -r requirements.txt
jupyter notebook
```

Open a notebook and run all cells. By default, Ex2/Ex3 load the pretrained parameters and display the model structure and physical parameters where applicable. View the training history in TensorBoard.

| Switch | Default | Usage |
|---|---|---|
| `RUN_TRAINING` | `False` | Load pretrained parameters. Set to `True` to train the model. |
| `RUN_BENCHMARK` | `False` | In Ex1, read saved timings. Set to `True` to rerun the gradient benchmark. |

For MHE training and the Ex1 benchmark, install **acados** and its Python interface following the [official installation guide](https://docs.acados.org/installation/index.html).

Training and benchmark outputs are written to `runs/new/<experiment>_<timestamp>/`.

`Ex1_plot.ipynb` reads the timing data in `runs/Ex1/` and saves the figure to `results/Ex1/`.

To view the saved training curves:

```sh
tensorboard --logdir runs
```

## Using PEM-MHE for another system

Start from a PEM-MHE notebook:

- **Configure the system.** Keep dimensions `nx`, `nu`, `nw`, horizon `N`, sample time, measurement matrix `C`, process-noise matrix `E`, initial parameters, and arrival/noise weights together in the **Configuration** cell. Measurements use `y = Cx`, with diagonal arrival precision.
- **Define the dynamics.** Provide matching PyTorch and CasADi implementations. The PyTorch callback returns `f(x, u, theta)`; the CasADi callback also includes `E @ w`.
- **Prepare the data.** Use `data[split]["u"]` with shape `(windows, N, nu)` and `data[split]["y"]` with shape `(windows, N, ny)`. Measurements correspond to `x_1, …, x_N`; the last measurement is reserved for the outer prediction error.
- **Build the model and initialization.** Replace `make_vehicle`, `make_mhe_config`, and the vehicle-specific EKF/grid initialization with your own `Dynamics`, `MHEConfig`, and initial state trajectories.
- **Run identification.** Pass them to `PEMMHE(model, config, data)` and follow the notebook's optimization loop using `problem.estimate(split)` and `problem.backward()`.
